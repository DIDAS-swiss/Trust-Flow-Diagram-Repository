How trust and data move in the Swiss e-ID

The Swiss e-ID trust infrastructure looks similar on paper across use cases — issue a credential, hold it in a wallet, present it, verify it — but the details differ a lot depending on context. This repo collects concrete, worked examples so that "how does trust actually flow here" has a diagram to point to, instead of a vague description.

Work in progress — for discussion purposes only. These diagrams are not official flows of the swiyu team or any other authority. This applies in particular to the Basic Flow. Diagrams may be updated and republished over time as discussions continue and the trust flows evolve.

Flows

Each flow is filed under a sector and a use case family. Sector names come from NOGA 2025, the Federal Statistical Office's classification of economic activities, so the division number beside each label means the same thing here, in an EU register and in a UN statistical office. About this repository

This is a community contribution in the spirit of DIDAS's Trust Flow Diagrams initiative — a shared, worked-example repository for the Swiss Trust Infrastructure. Flows are modeled eighter using LikeC4 or a Miro Flow exported as an svg file.
